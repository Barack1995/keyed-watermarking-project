SERVICE DEMONSTRATIONS
Fake clock starts at 0 seconds. Rate limit: 20 requests per 60 seconds.

DEMO 1: invalid token is rejected
$ python client.py --token-file secrets/bad_token.txt --detect data/passages/evaluation/watermarking/E-W-01.txt
{
  "outcome": "rejected: invalid credential"
}

DEMO 2: submitter may detect, but may not read the log
$ python client.py --token-file secrets/alice_token.txt --detect data/passages/evaluation/watermarking/E-W-01.txt
{
  "outcome": "ok",
  "score": 0.56,
  "flagged": false
}
$ python client.py --token-file secrets/alice_token.txt --read-log
{
  "outcome": "denied: not permitted"
}

DEMO 3: rate limit survives client restarts
Alice already used 1 request in Demo 2. Each request below is a NEW client program.
Sent 19 more requests (20 in total) with 19 separate client programs.
Request 21, from yet another new client program:
$ python client.py --token-file secrets/alice_token.txt --detect data/passages/evaluation/watermarking/E-W-01.txt
{
  "outcome": "rate_limited"
}
Referee moves the fake clock forward 60 seconds. New window:
$ python client.py --token-file secrets/alice_token.txt --detect data/passages/evaluation/watermarking/E-W-01.txt
{
  "outcome": "ok",
  "score": 0.56,
  "flagged": false
}
